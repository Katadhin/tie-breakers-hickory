# Tie Breakers Hickory

Concept location page for **Tie Breakers Hickory** (The Crossing at Hollar Mill, 883 Highland Ave SE, Hickory, NC 28602), built to sit under the Locations menu at tiebreakersnc.com.

Static site, no build step:
- `index.html` — the page (hero, On Our Screens, specials, the Michael Waltrip Signature Bar, buzz, news, visit, Privacy/Terms)
- `games.json` — the "On Our Screens" lineup; a scheduled task rewrites this file and Netlify redeploys
- `tie-breakers-logo.png`, `photos/` — assets

Specials, hours and the legal pages are drafts for the venue to confirm before publishing.
